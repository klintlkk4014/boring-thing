記憶單元 (MU) — 存放程式指令、待處理資料與運算結果
  • 輸入單元 (IU)：將外界資料轉為二進位訊號輸入電腦。
  • 輸出單元 (OU)：將運算結果呈現給使用者（例如第 2 題列印設備）。
  • 控制單元 (CU)：解碼指令、控制電腦運作，比喻為「總指揮」、「大腦指揮官」（第 11 題星際迷航船長）。
  • 算術邏輯單元 (ALU)：負責計算與條件比對（第 9 題雲端中心海量比對運算）。
  • 記憶單元 (MU)：存放電腦程式與資料（第 3、4 題陷阱：不單單只放輸入待處理資料！）。
⚡

CPU 與運算效能指標

  • CPU 組成：由 控制單元 (CU) + 算術邏輯單元 (ALU) + 暫存器 (Registers) 組成（第 5 題）。
  • 64 位元電腦意義：指 CPU 內部的 一般用途暫存器 (General Purpose Registers) 寬度以及一次能處理的資料長度為 64 位元（第 12 題重點！）。
  • MIPS 指標：Million Instructions Per Second（每秒百萬個指令數）。其中 I 代表 Instruction（指令）（第 10 題）。
  • 提升系統效能關鍵元件：CPU 升級、擴充主記憶體 (RAM)、升級高階獨立顯示卡或換裝高速 NVMe SSD；而鍵盤、滑鼠屬於輸入設備，更換無法提升主機運算效能（第 13 題）。
💾

記憶體家族大比拼 (SRAM vs DRAM)

特性 SRAM（靜態隨機存取） DRAM（動態隨機存取）
存取速度 極快（優勢！） 較慢
充電更新 (Refresh) 不需要 需要定時充電更新
製造成本 / 密度 成本高、積體密度低 成本低、密度高（容量大）
主要用途 CPU 快取記憶體 (L1/L2/L3 Cache) 電腦主記憶體 (DDR4 / DDR5 RAM)
考卷關聯 第 1 題（SRAM 優點） 第 8 題、第 12 題 (8GB 主記憶體)
🔌

插槽、匯流排與介面特性

  • 熱插拔 (Hot Swapping)：在電腦「開機運轉中」可以直接抽換連接設備，關機時亦可抽換（如 USB、隨身碟、外接硬碟），不需重新啟動主機（第 7 題）。
  • 主機板常見插槽用途：
    • 記憶體插槽 (DIMM / SO-DIMM)：筆電或桌機安插 RAM（第 8 題）。
    • PCI-Express (PCIe) 插槽：安裝獨立顯示卡、擴充高速介面卡。
    • M.2 插槽：安裝高速 NVMe / SATA SSD 固態硬碟或 Wi-Fi 無線網卡。
    • CPU 插槽 (Socket)：安裝中央處理器。
  • I/O 定義：Input / Output，即電腦系統與外部世界溝通的「輸入與輸出」（第 6 題）。

🎯 專屬提分複習處方

  1. 搞清楚 CPU 的三巨頭：牢記「中央處理單元 (CPU) = 控制單元 (CU) + 算術邏輯單元 (ALU) + 暫存器 (Registers)」，記憶單元 (MU) 屬於外部支援，千萬不要把 MU 選進 CPU 裡面！
  2. 文字陷阱破解：題目若出現「『僅』儲存輸入待處理資料」，通常有詐！記憶體 (MU) 不只要放待處理資料，更要存放「程式指令」以及「處理完成之資料」。
  3. 64 位元電腦本質：64 位元指的絕對不是時脈，也不是主記憶體或快取大小，而是 CPU 核心 一般用途暫存器 一次能容納的二進位位元寬度！
